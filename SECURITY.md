# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.2.x | ✅ |
| < 0.2 | ❌ (please upgrade) |

## Reporting a vulnerability

Open a **private** report via
[GitHub security advisories](https://github.com/salim-studio/mumpy/security/advisories/new)
or contact the maintainer through the email on the GitHub profile.
Please include a minimal reproduction and the affected version.
We aim to acknowledge within 72 hours.
